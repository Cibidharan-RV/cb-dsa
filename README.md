# cb-dsa

A Command Line Interface (CLI) tool for automating your Data Structures and Algorithms (DSA) problem-solving workflow. 

It helps you automatically create problem files, sync your LeetCode submissions, and generate detailed markdown documentation and statistics.

## Installation

```bash
pip install cb-dsa
```

## Usage

```bash
# Initialize inside your project folder
cb-dsa init

# Sync your recent accepted LeetCode submissions
cb-dsa sync

# Manually create a new problem template (grabs from clipboard)
cb-dsa create

# Re-generate the README.md and stats dashboard
cb-dsa generate
```
